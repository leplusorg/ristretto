# Source

Maven sources for the `ristretto` Java utility library.

- `main/java/org/leplus/ristretto/util/` — the public API: reproducible UUID
  helpers (`ReproducibleUUIDs`, `UUIDConvertor`) and identity-based collections
  (`IdentityHashSet`, `IdentityObject`, `ArrayListVector`, `VectorAdapter`, …).
- `test/java/org/leplus/ristretto/util/` — JUnit tests.

Build/test with `./mvnw test`.
